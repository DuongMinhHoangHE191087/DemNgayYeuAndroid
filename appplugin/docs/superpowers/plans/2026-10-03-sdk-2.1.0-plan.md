### C. Giấy phép (SA1/SA2; Q2 = Ed25519)
Token `ALP1.<b64url(payload)>.<b64url(sig64)>`; payload JSON (UTF-8, khoá cố định) `{"v":1,"kid":"<id>","pkg":"<applicationId>","certs":["<sha256 hex thường của DER>",…],"exp":<unix s>,"feat":["ads","brain"]}`; chữ ký Ed25519 (RFC 8032, PureEdDSA) trên byte ASCII `ALP1.<b64url(payload)>`. Meta-data `com.app.plugin.LICENSE` (string). Khoá công khai theo `kid` biên dịch trong `license/LicenseKeys.kt` (internal; `dev1` ở 2.1.0 tới O5, `k1` khi chủ dự án keygen). **Xác minh** một lần mỗi process trên luồng `appplugin-license` (bắt đầu ở `initPlugin` bước `meta`, đọc chuỗi từ cùng `metaData` của `dataBucketConfig` → 0 IPC thêm trên main; đọc cert = 1 IPC trên luồng license: API ≥ 28 `GET_SIGNING_CERTIFICATES`, 26–27 `GET_SIGNATURES`). Verdict `VALID | INVALID(<lý do cố định: missing, malformed, kid, sig, pkg, cert, expired, feat>) | PENDING`. **Hiệu lực:** INVALID → như kill `ads` + brain tắt: `AdSdkStartup.startAdNetworks` không khởi tạo mạng, `AdsHelper.isDisableAds` true, `AdsBrain` không quyết; **đúng 1** `logE` `license: INVALID (<lý do>) — quảng cáo và brain tắt`; không ném; IAP, consent, logevent giữ nguyên. VALID → 1 dòng `Log.i` thẳng (như `initPlugin ms`, đọc được khi flag log tắt) `license: VALID kid=<kid> exp=<yyyy-mm-dd>`. PENDING khi mạng sắp khởi tạo → task "ad networks" chờ verdict **trên luồng của nó** (≤ 2 s, hết hạn = INVALID(timeout) fail-closed #11); main 0 chờ (#9). `exp`: so `System.currentTimeMillis()`; quá hạn = INVALID(expired) — không có ân hạn ngầm. Fail-closed: mọi ngoại lệ trong xác minh = INVALID. R-P1: giấy phép không mở thứ consent đóng (DENIED vẫn chặn trước). Công cụ `tools/license_issue.py keygen --out <đường dẫn ngoài repo>` (đường dẫn trong repo → rc 2), `issue --key <f> --kid --pkg --cert <hex>… --days N --feat ads,brain`, `verify --pub <hex> <token>`; file khoá riêng mở đầu `ALPK1.` (mẫu #40 mới).
