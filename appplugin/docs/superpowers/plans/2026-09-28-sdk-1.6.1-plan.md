## Global Constraints

Nguyên văn brief (giữ chữ):

> - no public/protected API change (facade gate: new public symbol → FAIL; top-level `internal fun` → FAIL; signature change → FAIL; new members need explicit `internal`);
> - no push/tag/rebase/merge; one implementer per tree; one review per task; red→green logs; ledger;
> - every app request keeps exactly one terminal: load `onLoaded`/`onLoadFailed`; **show `onAdShowFail`/`onAdDismissed`, hoặc `false` đồng bộ — hợp đồng 1.3.1** (m6: `show*` trả `false` là kết thúc của request, SDK không gọi thêm callback; một số đường lỗi mạng đồng bộ gọi `onAdShowFail` rồi trả `false` — vẫn là một kết thúc. Review không flag lại điểm này);
> - no main-thread disk I/O (StrictMode G2 `by sdk = 0`, kể cả lần nạp prefs đầu, **ở cả hai chặng cold start** của `device_gate` từ Task 3);
> - consumer apps in ~/AndroidStudioProjects are read-only;
> - emulator: `am start`, not monkey (ngoài `device_gate`); screenshot before any close tap;
> - real devices: only demo install/uninstall + `device_gate`; rotation read before, restored after; no other setting.
