# - Chỉ dòng có `#` ở cột 0 là chú thích. Có khoảng trắng trước `#` thì dòng đó là regex. Dòng trống bỏ qua.

#   ( ) [ ] { } * + ? | ^ $ \ có nghĩa riêng: muốn khớp đúng chữ thì thêm \ phía trước (vd `\(`); `.` khớp mọi ký tự.
