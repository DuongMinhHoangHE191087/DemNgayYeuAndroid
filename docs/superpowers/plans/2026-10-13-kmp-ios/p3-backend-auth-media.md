# P3 - Backend/cloud, Auth, Media (KMP + iOS)

Phụ trách: P3 · Ngày 2026-10-13

> Trạng thái: bản đầy đủ, sẵn sàng cho review Codex vòng 1 (63 task B-, mục 10 có số liệu). Mọi quyết định ghi `DECIDED:`, mọi điều chưa kiểm chứng ghi `UNVERIFIED` kèm task hoặc kịch bản đóng.

## 1. Goal

Đưa toàn bộ tầng cloud, đăng nhập và media của InLove (Firebase Auth, Firestore, Cloud Functions, Cloudinary, hash/KDF, lưu bí mật, chọn/nén/tải ảnh-video) ra sau các gateway đặt ở `commonMain` (mỗi gateway có bản Fake cho test) để Android giữ nguyên hành vi và vẫn xanh sau từng task, còn iOS có bản triển khai đầy đủ: Swift bridge bọc Firebase iOS SDK 12.19.2 qua SPM (ghim đúng một phiên bản), Sign in with Apple kèm revoke token khi xoá tài khoản, Facebook qua Firebase OAuth web flow, cờ first-launch để dọn phiên Keychain còn sót sau khi gỡ app, PHPicker/camera cùng Ktor tải lên Cloudinary theo chữ ký do server cấp. Đồng thời siết phía server để không bypass được: `firestore.rules` có test bằng emulator, `entitlements/{uid}` chỉ Cloud Function được ghi, App Check (App Attest trên iOS) bắt buộc cho Firestore và Functions, và tính năng tốn tiền server phải kiểm quyền ở server chứ không chỉ ẩn nút ở UI.
